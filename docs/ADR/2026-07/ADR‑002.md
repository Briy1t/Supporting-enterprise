# ADR-002 — Migración del proyecto a JavaScript

## Fecha
29/07/2026

## Contexto
El frontend se creó inicialmente con plantilla React + TypeScript, generando archivos `.tsx` y configuración TypeScript que impedían la ejecución del proyecto.

## Decisión
Migrar el proyecto a JavaScript y eliminar soporte TypeScript.

## Razones
- Evitar errores de compilación.
- Simplificar el entorno para desarrollo inicial.
- Mantener coherencia con el backend en Python.
- Reducir complejidad mientras se construye la plataforma.

## Alternativas descartadas
- Mantener TypeScript y corregir configuración.
- Reinstalar plantilla React con TS correctamente.

## Consecuencias
- Eliminación de archivos `.tsx`.
- Renombrado de `vite.config.ts` a `vite.config.js`.
- Ajuste del script en `index.html`.

## Estado
Aprobado.
