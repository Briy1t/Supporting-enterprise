# ADR-019 — La Web Pública NO debe crear usuarios

## Decisión
Eliminar la creación de usuarios desde la web pública.

## Razones
- Riesgo de duplicados
- Riesgo de spam
- Riesgo de bots
- Vulnerabilidades
- Credenciales sin contrato real

## Nueva arquitectura
La web:
- recibe formularios
- guarda leads
- envía leads a la plataforma

La plataforma:
- revisa leads
- crea clientes reales
- genera credenciales
- asigna servicios

## Resultado
Sistema seguro, profesional y escalable.
