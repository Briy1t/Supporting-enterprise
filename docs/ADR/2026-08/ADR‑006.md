# ADR-006 — Eliminación de archivos .tsx y corrección de Vite

## Fecha
29/07/2026

## Contexto
Los archivos `.tsx` impedían la ejecución del frontend y generaban errores en Vite.

## Decisión
Eliminar archivos `.tsx`, corregir el script del HTML y renombrar `vite.config.ts`.

## Razones
- React no cargaba por incompatibilidad TS.
- El script apuntaba a `main.tsx`, archivo inexistente.
- Vite estaba configurado para TypeScript.

## Alternativas descartadas
- Mantener TS y corregir configuración.
- Reinstalar plantilla TS.

## Consecuencias
- Frontend funcional.
- Configuración limpia y coherente.

## Estado
Aprobado.
