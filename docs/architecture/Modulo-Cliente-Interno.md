# Módulo Interno de Cliente — Supporting Enterprise

El módulo interno de cliente será accesible mediante:

`/clientes/{id}`

## Contenido de la página

- Datos del cliente:
  - nombre
  - empresa
  - email
  - teléfono
  - preferencia de contacto (WhatsApp, correo, llamada)
- Servicios contratados (multi selección).
- Tickets asociados.
- Estado del cliente (activo, inactivo).
- Historial de acciones.

## Acciones disponibles

- Editar datos del cliente.
- Activar / desactivar cliente.
- Añadir servicio.
- Ver tickets.
- Crear ticket.
- Eliminar cliente.

## Objetivo
- Evitar duplicados.
- Centralizar toda la información del cliente.
- Conectar datos provenientes de la web (formularios) con la plataforma interna.
