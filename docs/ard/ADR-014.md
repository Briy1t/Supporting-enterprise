# ADR-009 — Conversión de páginas estáticas a dinámicas

## Decisión
Convertir páginas estáticas (Técnicos, Servicios, Alertas) en módulos dinámicos conectados al backend.

## Razones
- Datos en tiempo real
- Escalabilidad
- Profesionalización del sistema

## Consecuencias
- Requiere endpoints reales
- Requiere integración con FastAPI
