# ADR-015 — Arquitectura Multiroles y Acceso Unificado

## Decisión
Implementar un sistema de login único que devuelve un JWT con rol y redirige automáticamente al panel correspondiente.

## Razones
- Seguridad empresarial
- Escalabilidad
- UX profesional
- Separación clara entre Web Corporativa y Plataforma Empresarial

## Consecuencias
- Requiere middleware de roles en React.
- Requiere validación estricta en FastAPI.
- Permite añadir nuevos roles sin modificar la base.
