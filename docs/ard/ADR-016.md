# ADR-016 — Uso de Alembic para Migraciones

## Decisión
Adoptar Alembic como sistema oficial de migraciones para SUPPORTING Enterprise.

## Razones
- Control de versiones de la base.
- Migraciones seguras.
- Historial de cambios.
- Integración futura con CI/CD.
- Evitar create_all en producción.

## Consecuencias
- Requiere configuración inicial.
- Requiere importar todos los modelos.
- Flujo de trabajo basado en autogenerate.
