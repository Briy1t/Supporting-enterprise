# ADR-007 — Creación de servicios en el frontend

## Fecha
29/07/2026

## Contexto
El frontend necesita consumir la API del backend de forma organizada y reutilizable.

## Decisión
Crear servicios independientes para cada área del negocio.

## Razones
- Facilita el consumo de la API.
- Evita duplicación de código.
- Permite centralizar errores y autenticación.
- Mantiene el frontend limpio y profesional.

## Alternativas descartadas
- Llamadas fetch directamente en componentes.
- Un solo archivo de servicios para todo.

## Consecuencias
- Frontend más mantenible.
- Mejor separación de responsabilidades.

## Estado
Aprobado.
