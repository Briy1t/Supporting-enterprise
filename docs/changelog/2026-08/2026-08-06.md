# CHANGELOG — 06/08/2026

- Limpieza completa de tablas corruptas.
- Reestructuración de modelos Pydantic con ConfigDict.
- Reconfiguración del backend para evitar conflictos entre máquinas.
- Documentación del flujo correcto de creación de tablas.

- Eliminación de tablas antiguas y relaciones obsoletas.
- Ajuste del modelo de clientes para evitar errores de serialización.
- Corrección del comportamiento de FastAPI al crear tablas.

## Fixed
- Error 500 en creación de clientes.
- Conflicto entre dos instancias FastAPI generando estructuras distintas.
- Problemas de Swagger al leer modelos inconsistentes.

## Notes
- Se establece la regla: **solo una máquina debe crear tablas; la otra solo debe usarlas**.
