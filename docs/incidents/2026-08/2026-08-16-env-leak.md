## ⚠️ Incidencia: Exposición de `.env`

### Descripción
El archivo `.env` fue subido accidentalmente al repositorio público/compartido.

### Acciones tomadas
* 🛑 **Eliminación inmediata** del archivo del repositorio.
*  **Limpieza del historial** de Git (usando herramientas como `git filter-repo` o `BFG Repo-Cleaner`) para borrar cualquier rastro de las credenciales.
* **Regeneración completa** de todas las claves, tokens y contraseñas expuestas.
*  **Actualización de variables** en el entorno de producción con las nuevas credenciales.
