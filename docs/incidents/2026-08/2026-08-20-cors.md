## Incidencia: CORS bloquea todas las peticiones

### Detalle del Error
Al realizar peticiones desde el cliente hacia el servidor, las consultas fallan arrojando el siguiente mensaje en la consola del navegador:

```text
Access to fetch… has been blocked by CORS policy.
```

### Causa
El backend no está enviando el encabezado HTTP obligatorio `Access-Control-Allow-Origin`, lo que impide que el navegador valide y permita el intercambio de recursos entre distintos orígenes (Frontend en puerto `5173` y Backend).

### Solución
Se debe configurar el middleware de CORS en el archivo principal de **FastAPI** para habilitar explícitamente el acceso desde el entorno de desarrollo local:

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```
