# Integración Frontend ↔ Backend

## Objetivo
Conectar React con FastAPI para obtener datos en tiempo real.

## Áreas que requieren integración
- Clientes
- Técnicos
- Servicios
- Alertas
- Tickets
- Administración

## Requisitos
- API REST funcional
- WebSockets para tiempo real
- Cron jobs para tareas automáticas
- Roles y permisos
- Auditoría de acciones
