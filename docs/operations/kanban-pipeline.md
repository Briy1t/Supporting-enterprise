## Kanban Administrativo (Pipeline visual)
El slider se reemplaza por un Kanban, el cual es más escalable y profesional.

### Columnas del pipeline
`Pendientes` ➔ `Llamados` ➔ `Esperando respuesta` ➔ `Aceptados` ➔ `Descartados`

### Beneficios
* **Desarrollo y Código:**
  * Más fácil de mantener.
  * Más fácil de escalar.
  * Evita errores de sintaxis.
  * Evita errores de Vite/OXC.
* **Experiencia de Usuario (UX):**
  * Permite *drag & drop* (arrastrar y soltar).
  * Permite el uso de filtros.
  * Permite establecer prioridades.
  * Permite paginación.
  * Permite búsquedas rápidas.
